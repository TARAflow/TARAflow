## TARAflow 0.17.2-beta

Bug fix release: switching or closing projects could move data of one project into another.

### Fixed

- **Risks in the wrong project:** with the Risk tab open in two projects, closing one could copy all of its risks into the other. Each project now has its own Risk tab; a save always goes to the project it was made in, and an edit made just before the switch is kept.
- **Hazards, audit settings, Overview:** the same kind of mix-up could carry hazards, author / signing settings, an open *Project info* edit or a late source binding result into another project. Fixed the same way.
- **Attack trees:** a change made in the last second before a project switch is no longer lost (DSL typed in the last half second still is).

### Please check

A project that was open together with another one may already contain data that does not belong to it (risks, hazards, Overview data). It is not repaired automatically — please check and remove it.

### Compatibility

No new project schema (still **12**): projects of 0.17.1-beta open unchanged, and 0.17.1-beta still opens files saved by 0.17.2-beta.
