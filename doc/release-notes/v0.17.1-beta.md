## TARAflow 0.17.1-beta

Bug fix release for EN 50742 machinery projects.

### Fixed

- **Hazard tab missing:** a project tagged EN 50742 (or another regulation that mandates hazard analysis) now always shows the Hazard tab — the *Safety Analysis* setting is taken from the tags when the project is opened, also when the file was written outside TARAflow.
- **Out-of-scope hazards:** a hazard marked *out of scope* (protective measure purely mechanical or organisational) no longer needs a contributing asset; an imported risk assessment validates without errors. Unreviewed and in-scope hazards are still checked.
- **Exposure level of data flows:** a flow that no longer crosses a trust boundary loses its derived exposure level instead of keeping a stale one.

### Changed

- **Compliance tab:** with both IEC 62443 tags the classic and the CRA edition appear side by side as sub-tabs.

### Compatibility

No new project schema (still **12**): projects of 0.17.0-beta open unchanged, and 0.17.0-beta still opens files saved by 0.17.1-beta. Files saved by a 0.18 development build (schema 13) do not open in 0.17.x.
