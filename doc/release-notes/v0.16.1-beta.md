## TARAflow 0.16.1-beta

Bug fix release.

### Fixed

- **Converting an older project:** when a project from an early schema was opened, the list of conversion steps could be longer than the window — the dialog grew past the screen and *Convert* / *Cancel* were out of reach. The dialog now fits the window: the text scrolls, the buttons always stay visible.
- **Confirmation dialogs** with a long message scroll the same way.

### Compatibility

No new project schema (still **11**): projects of 0.16.0-beta open unchanged, and 0.16.0-beta still opens files saved by 0.16.1-beta.
